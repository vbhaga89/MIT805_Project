\section{Dataset Size and Characteristics}

The raw dataset available on Kaggle is 41.62 GB. The working dataset that was used for preprocessing was the \emph{LI\_Large\_Trans.csv} file on Kaggle that is 16.74 GB. Table 
\ref{tab:li_large_columns} describes the columns in the table. The data collection period for this file is from 1 August 2022 - 5 November 2022. It was published in 2023 and was last updated in November 2025. The processing dataset used will be the same as the working dataset (16.74 GB).
