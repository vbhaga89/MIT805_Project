\section{Data Provenance and Description}

The dataset used for this project is the IBM Transactions for Anti Money Laundering (AML) dataset. It is a large synthetic financial transaction dataset designed to support research and experimentation in anti-money laundering (AML) detection, containing both legitimate and laundered transactions. The dataset is publicly available on Kaggle at the following link: \href{https://www.kaggle.com/datasets/ealtman2019/ibm-transactions-for-anti-money-laundering-aml?select=HI-Large_Trans.csv}{AML Dataset}. The dataset uses the \href{https://cdla.dev/sharing-1-0/}{Community Data License Agreement (Sharing, Version 1.0)} which states that the dataset can be used for
academic and research purposes.
